# M22 Test Report — System Dynamics Simulation Engine

## Verification environment

M22 was verified in the packaging container using Python 3.13. The container
does not have the optional `simpy` and `groq` dependencies required by the
legacy DES runtime/AI interpreter test modules.

## Results

- Python compilation via `python -m compileall` for the new backend and all
  integration modules — **passed**.
- Focused M22 and integration selection covering system dynamics model/backend,
  M7 readiness, M8 compilation, M9 execution, M13 workspace registry,
  M14 web API, mathematical/common compiler/execution regression —
  **109 passed, 1 warning**.
- `python -m pytest -q --ignore=tests/des` — **529 passed, 1 warning**.
- `python -m pytest -q tests/des/test_replay.py` — **15 passed**.
- `python -m simulations.system_dynamics.demo` — completed; 400 RK4 steps over
  80 days, 401 snapshots, and population conservation at 1000.000000000.

The single warning in the broader selection is the expected duplicate ZIP path
warning generated by the workspace import rejection test.

## Full-suite limitation

The full `python -m pytest -q` collection in this packaging container cannot
complete because `simpy` and `groq` are not installed. Earlier collection
identified imports from the DES runtime/backend tests that require `simpy`,
and DES interpreter/pipeline tests that require `groq`. The DES replay
projection suite, which does not need those optional runtime packages, was run
separately and passed. The complete suite must still be run in the user's
Windows environment after applying M22.

## Coverage

The M22 tests cover model schema and identifier validation, safe expression
validation, auxiliary dependency ordering and cycle rejection, Euler/Heun/RK4
execution, directed and external flows, stock bounds, population conservation,
M7 readiness, M8 provenance-bound compilation, M9 trace/fingerprint
serialization, parameter sweeps, M13 extension registration, and M14 readiness
API support.

## Interpretation caveat

The SIR demonstration uses synthetic equations and illustrative parameters.
Its conservation check verifies internal accounting in that example; it does
not establish that the equations or parameters describe a real epidemic.
