Plan template: scenarios/analytics/plan_template.json
The template contains M10/M11/M23/M24 source slots. Edit every report path to a real integrity-verified report under the source root. Edit metric names and units to exact source values. M23 objective reports do not store objective units; set the matching M25 metric unit to null. The M25 semantic definition is a user assertion, not automatic equivalence verification.

Standalone run example:
   python -m analytics.cli --plan scenarios/analytics/plan_template.json --source-root . --output-dir outputs/analytics

Inspect a saved report:
   python -m analytics.cli --inspect outputs/analytics/<m25-report>.json

Main menu: option 22 runs M25 analytics; option 23 inspects a saved M25 report.
